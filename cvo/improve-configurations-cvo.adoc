= Implemente configurações de sistema Cloud Volumes ONTAP bem arquitetadas
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp ajuda você a implementar as melhores práticas para os seus sistemas Cloud Volumes ONTAP em execução no armazenamento do Microsoft Azure, usando insights e recomendações de análise de configuração. Você pode revisar o status de arquitetura adequada, identificar problemas em suas configurações e obter recomendações para aprimorar a arquitetura de sistemas que não estão otimizados para confiabilidade, segurança, eficiência, desempenho e custo.

Você também pode descartar a análise de configurações de armazenamento específicas que não se aplicam ao seu ambiente de storage para evitar alertas desnecessários e resultados de otimização imprecisos.

link:configuration-analysis-cvo.html["Saiba mais sobre a análise de configuração e o status de arquitetura bem projetada."]



[[about-this-task]]
== Sobre esta tarefa

O Workload Factory analisa as configurações do sistema Cloud Volumes ONTAP no Microsoft Azure todos os dias. A análise diária fornece o status bem arquitetado, insights e recomendações. Você pode corrigir automaticamente problemas de configuração para atender às melhores práticas.

A conectividade do agente Link ou Console permite que o Workload Factory realize uma varredura completa dos seus Cloud Volumes ONTAP em busca de problemas de desempenho, proteção de dados e configurações. Isso garante que você receba informações e recomendações precisas para otimizar seus Cloud Volumes ONTAP.

Os requisitos de configuração de storage variam. Você pode dispensar a análise de configurações específicas que não se aplicam ao seu ambiente de storage. Dispensar configurações que não se aplicam ajuda você a evitar alertas desnecessários e resultados de otimização imprecisos.



[[before-you-begin]]
== Antes de começar

* Você precisa link:https://console.netapp.com/add-working-environment/choose-type["adicionar um sistema Cloud Volumes ONTAP"] acessar o NetApp Console para visualizar o status da arquitetura adequada e as recomendações para problemas de configuração.
* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html["Você deve implantar um agente do Console"] para a análise mais completa dos recursos do seu sistema.
* Permita conectividade de rede de saída para os seguintes endpoints:
+
** \https://api.workloads.netapp.com
** \https://ws.workloads.bluexp.netapp.com






[[view-recommendations-for-configuration-issues]]
== Veja recomendações para problemas de configuração

Você pode visualizar as recomendações para problemas de configuração após a conclusão da análise diária. As recomendações explicam as melhores práticas e os riscos potenciais de configurações não otimizadas. Você também pode baixar um arquivo CSV das recomendações.

.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. No painel de controle Well-architected, selecione *Visualizar* para qualquer configuração.
+
Opcionalmente, selecione image:button_download.png["Uma captura de tela do ícone de download"]para baixar um arquivo CSV com as recomendações para todas as configurações.

. Analise a recomendação.




[[fix-a-configuration-issue]]
== Corrigir um problema de configuração

Você pode corrigir problemas de configuração para um sistema Cloud Volumes ONTAP ou para volumes selecionados em um sistema de arquivos. Você pode selecionar uma ou mais configurações para corrigir.

O processo de correção pode causar indisponibilidade de instâncias ou interrupções de serviço. Analise cuidadosamente cada recomendação antes de corrigir um problema de configuração.

.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. No painel de controle Well-architected, selecione *Visualizar* para qualquer configuração.
+
Certifique-se de revisar a recomendação cuidadosamente. A recomendação explica as melhores práticas e possíveis armadilhas de configurações não otimizadas.

. Selecione *Corrigir* para um único volume ou *Visualizar e corrigir* para vários volumes. Para vários volumes, selecione os volumes afetados para corrigir.
. Analise o resumo e as ações que aparecem na caixa de diálogo para saber o que acontece se você corrigir o problema. Algumas operações podem causar indisponibilidade da instância ou interrupções de serviço.
. Selecione *Continuar* para corrigir o problema de configuração.


.Resultado
O Workload Factory inicia o processo para corrigir o problema. Selecione o menu de configurações da conta e, em seguida, selecione *Tracker* para visualizar o status da operação.



[[dismiss-a-configuration-analysis]]
== Descartar uma análise de configuração

Interrompa a análise de configuração de um sistema Cloud Volumes ONTAP ou de volumes selecionados. Você pode reiniciar a análise quando necessário.

[role="tabbed-block"]
====
.Descartar uma análise de configuração para um sistema
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. No painel de controle Well-architected, selecione *Visualizar* para qualquer configuração.
. Em Configurações, identifique a configuração que não se aplica ao seu ambiente e selecione *Dismiss*.
. Na caixa de diálogo Dispensar configuração, selecione *Dispensar* para interromper a análise de configuração.


--
.Descartar uma análise de configuração para um volume
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. No painel de controle Well-architected, selecione *Visualizar* para qualquer configuração.
. Em Configurações, identifique a configuração a descartar para os volumes selecionados e, em seguida, selecione *Exibir e corrigir*.
. Identifique os volumes a serem descartados da análise de configuração.
+
** Para um volume: selecione o menu de ações e depois selecione *Dispensar volume*.
** Para vários volumes: selecione os volumes e, em seguida, selecione *Ignorar* ao lado de Bulk action.


. Selecione *Ignorar* para interromper a análise da configuração.
. Na caixa de diálogo Dispensar volumes, selecione *Dispensar* para confirmar.


--
====
.Resultado
A análise de configuração é interrompida para o sistema ou volumes selecionados.

Você pode reativar a análise a qualquer momento.



[[reactivate-a-dismissed-configuration-analysis]]
== Reative uma análise de configuração descartada

Reative a análise de configuração descartada para um sistema Cloud Volumes ONTAP a qualquer momento. Você pode selecionar uma ou mais configurações para reativar.

[role="tabbed-block"]
====
.Reativar uma análise de configuração para um sistema
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. Selecione *Dismissed configurations*.
. Identifique a configuração que você deseja reativar e selecione *Reativar*.


--
.Reative uma análise de configuração para um volume
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. Selecione *Dismissed configurations*.
. Identifique o(s) volume(s) para reativar a partir da análise de configuração.
+
** Para um volume: selecione o menu de ações e então selecione *Reativar volume*.
** Para vários volumes: selecione os volumes e, em seguida, selecione *Reativar* ao lado de Bulk action.




--
====
.Resultado
O sistema reativa a análise de configuração. Uma nova análise ocorre diariamente.
