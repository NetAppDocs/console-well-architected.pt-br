=== Suporte a FSx for ONTAP no painel bem arquitetado no NetApp Console

[[well-architected-issues-displayed-in-netapp-console-systems-page]]
=== Problemas bem arquitetados exibidos na página de Sistemas da NetApp Console

As notificações para problemas de arquitetura bem definida estão disponíveis para o Cloud Volumes ONTAP no Microsoft Azure na página Sistemas de gerenciamento de storage no NetApp Console. Esse recurso ajuda você a identificar rapidamente problemas de configuração em seus sistemas Cloud Volumes ONTAP no Azure e a navegar até o painel de arquitetura bem definida de cargas de trabalho a partir da notificação.
