= Implemente configurações bem arquitetadas do Google Cloud NetApp Volumes
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp ajuda você a implementar as melhores práticas para seus pools de storage do Google Cloud NetApp Volumes usando insights e recomendações de análise de configuração. Você pode revisar o status de arquitetura bem definida, identificar problemas em suas configurações e receber recomendações para aprimorar a arquitetura de quaisquer pools de storage que não estejam otimizados para confiabilidade, segurança, eficiência, desempenho e custo.

link:configuration-analysis-gcnv.html["Saiba mais sobre a análise de configuração e o status de arquitetura bem projetada."]



[[about-this-task]]
== Sobre esta tarefa

NetApp analisa as configurações dos seus pools de storage do Google Cloud NetApp Volumes todos os dias. A análise diária fornece o status de arquitetura bem definida, além de insights e recomendações para ajudar você a entender problemas de configuração, garantindo que seus pools de storage sigam as melhores práticas.

A conectividade do agente Link ou Console permite que o Workload Factory realize uma verificação completa dos seus sistemas de arquivos em busca de problemas de desempenho, proteção de dados e configurações. Como resultado, você recebe insights precisos e recomendações para otimizar os pools de storage do Google Cloud NetApp Volumes.

Os requisitos de configuração de storage variam. Você pode dispensar a análise de configurações específicas que não se aplicam ao seu ambiente de storage. Dispensar configurações que não se aplicam ajuda você a evitar alertas desnecessários e resultados de otimização imprecisos.

Após a conclusão da análise diária, o painel de controle de arquitetura bem estruturada exibe o número total de recursos bem estruturados, o número de recursos em estado crítico e o número de recursos em estado de alerta. As configurações são categorizadas pelos pilares da estrutura bem arquitetada: confiabilidade, excelência operacional, otimização de custos, eficiência de desempenho e segurança. O painel de controle também inclui uma tabela que lista todas as configurações. Para cada configuração, a tabela mostra:

* O status de bem-arquitetado
* A gravidade
* A categoria
* O tipo de recurso (volume ou pool de storage)
* Recursos afetados
* A opção de visualizar a recomendação quando a configuração não estiver otimizada




[[before-you-begin]]
== Antes de começar

* Você precisa link:https://console.netapp.com/add-working-environment/choose-type["adicionar um Google Cloud NetApp Volumes pool de storage"] acessar o NetApp Console para visualizar o status da arquitetura adequada e as recomendações para problemas de configuração.




[[view-recommendations-for-configuration-issues]]
== Veja recomendações para problemas de configuração

Você pode visualizar as recomendações para problemas de configuração após a conclusão da análise diária. As recomendações explicam as melhores práticas e os riscos potenciais de configurações não otimizadas. Você também pode baixar um arquivo CSV das recomendações.

.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. No painel de controle Well-architected, selecione *Visualizar* para qualquer configuração.
+
Opcionalmente, selecione image:button_download.png["Uma captura de tela do ícone de download"] para baixar um arquivo CSV com as recomendações para todas as configurações.

. Analise a recomendação.




[[dismiss-a-configuration-analysis]]
== Descartar uma análise de configuração

Interrompa a análise de configuração para um Google Cloud NetApp Volumes pool de storage ou para volumes selecionados. Você pode reiniciar a análise quando necessário.

[role="tabbed-block"]
====
.Descartar uma análise de configuração para um pool de storage
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. No painel de controle Well-architected, selecione *Visualizar* para qualquer configuração.
. Em Configurações, identifique a configuração que não se aplica ao seu ambiente e selecione *Dismiss*.
. Na caixa de diálogo Dispensar configuração, selecione *Dispensar* para interromper a análise de configuração.


--
.Descartar uma análise de configuração para um volume
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. No painel de controle Well-architected, selecione *Visualizar* para qualquer configuração.
. Em Configurações, identifique a configuração que deseja descartar para os volumes selecionados e, em seguida, selecione *View*.
. Identifique os volumes a serem descartados da análise de configuração.
+
** Para um volume: selecione o menu de ações e depois selecione *Dispensar volume*.
** Para vários volumes: selecione os volumes e, em seguida, selecione *Ignorar* ao lado de Bulk action.


. Selecione *Ignorar* para interromper a análise da configuração.
. Na caixa de diálogo Dispensar volumes, selecione *Dispensar* para confirmar.


--
====
.Resultado
A análise de configuração é interrompida para o pool de storage ou volumes selecionados.

Você pode reativar a análise a qualquer momento.



[[reactivate-a-dismissed-configuration-analysis]]
== Reative uma análise de configuração descartada

Reative uma análise de configuração descartada a qualquer momento. Você pode selecionar uma ou mais configurações para reativar.

[role="tabbed-block"]
====
.Reative uma análise de configuração para um pool de storage
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. Selecione *Dismissed configurations*.
. Identifique a configuração que você deseja reativar e selecione *Reativar*.


--
.Reative uma análise de configuração para um volume
--
.Passos
. Faça login no link:https://console.netapp.com/home["NetApp Console"^].
. No menu NetApp Console, selecione *Workloads* e depois *Well-architected*.
. Selecione *Dismissed configurations*.
. Identifique os volumes a serem reativados a partir da análise de configuração.
+
** Para um volume: selecione o menu de ações e então selecione *Reativar volume*.
** Para vários volumes: selecione os volumes e, em seguida, selecione *Reativar* ao lado de Bulk action.




--
====
.Resultado
O sistema reativa a análise de configuração. Uma nova análise ocorre diariamente.
